I was back on the
[PurePerformance](https://www.spreaker.com/episode/blueprints-for-otel-success-standardizing-observability-at-scale-with-dan-gomez-blanco--72894139)
podcast to talk about OTel Blueprints and Reference Implementations. There is no single way to deploy OpenTelemetry at
scale, so we looked at how the community is turning that complexity into shared guidance on data standards, consistent
agent and Collector configuration, pipeline resilience and sampling, using real-world reference architectures from
organisations like Skyscanner, Adobe and Mastodon.
